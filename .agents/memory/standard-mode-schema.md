## Current configuration (restored after speed-patch reversal)

Schema includes:
- `questionTranslation` (4 fields) — generated by model; cleared post-generation for factual/recall/MCQ by `questionNeedsTranslation()` classifier
- `guidedReasoning` — exactly 4 steps with `pause` field
- `finalAnswer` — `answer` + `whyCorrect` + `verification`

Schema excludes:
- `practiceQuestion` — intentionally absent; saves ~220 tokens (~1.7 s); model sometimes hallucinates it anyway → stripped post-generation

`maxTokens`: **1100** (was 600 in speed-patch era; safe minimum for 4-step schema without practiceQuestion)

## Post-generation strip block (Standard mode only)

Located in `solveQuestion.ts` inside the `try { draftResult = ... }` block, after `generateDraft`:

1. `questionNeedsTranslation(q)` → clears all 4 QT fields if factual/recall/MCQ
2. Always clears `practiceQuestion.question`, `hints`, `solution` if the field was hallucinated

**Why:** The frontend `TeachingLayout.tsx` guard is `!!lesson.practiceQuestion?.question` — it correctly hides the section when question is empty string. The object presence alone does not cause rendering.

## Prior speed-patch state (do not restore)

- 3 steps, no pause, no questionTranslation, no whyCorrect, maxTokens=600
- Caused: circular proof reasoning, blueprint mapping errors at 600 tokens, scaffolding loss for weak students
