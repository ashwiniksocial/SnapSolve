### Required behaviour

**Explain it more simply**

* Use the existing solve pipeline.
* Add one transient request intent such as `simplify`.
* Carry it through the existing client transport to `POST /api/solveQuestion`.
* Resolve intent server-side before generation.
* Generate a genuinely simpler explanation for the existing question/solution.
* Do NOT change the student's saved/global explanation-level preference.
* Do NOT create a new AI engine, router, service or prompt framework.
* Prevent normal cached content from being incorrectly returned for this intent using the smallest safe cache change.

**Show me visually**

* No fresh AI call.
* Reuse `lesson.intuition.visual`.
* Reveal/focus it in a simple dedicated presentation.
* Do not add image generation or diagram infrastructure.

**Quick revision**

* No fresh AI call.
* Reuse existing lesson fields, prioritising:
  `rememberThese`,
  `retrievalPractice`,
  `confidenceCheck`,
  `confidenceBuilder`.
* Present only the useful available content; avoid placeholder/empty sections.

**Practise**

* No fresh AI call initially.
* Reuse the existing `practiceQuestion`, hints and solution.
* Reuse existing practice components/navigation where possible.
