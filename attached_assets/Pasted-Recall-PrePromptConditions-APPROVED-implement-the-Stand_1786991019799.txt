1. STANDARD GENERATION RULE
==================================================

In JSON_SCHEMA_STANDARD only:

For simple factual / recall / definition / straightforward MCQ questions where there is genuinely nothing useful to decompose:

- questionTranslation.plainEnglish = ""
- questionTranslation.whatWeKnow = ""
- questionTranslation.whatWeFind = ""
- questionTranslation.wordToMath = ""

Do NOT generate paraphrased filler merely to populate the section.

Examples that normally should NOT need "Understand the Question":

"What is another name for the Cartesian plane?"
"Define displacement."
"Which of the following is..."
"Name..."
"State..."

BUT do not classify solely from these opening words.

If interpreting the question genuinely helps the student — calculation, word problem, proof, multi-condition problem, difficult reasoning, meaningful multi-part question — retain and populate the section.

Examples where it SHOULD remain:

- given numerical values must be extracted;
- quantities/units must be identified;
- words must be translated into mathematics;
- proof assumptions need clarification;
- multiple conditions must be organised;
- the wording is genuinely difficult for a weak student.
